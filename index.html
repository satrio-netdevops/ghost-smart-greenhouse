Arsitektur Perangkat Lunak

Edge Processing Node

Firmware ESP32 menggunakan Non-Blocking State Machine berbasis asinkron millis() dan Direct Hardware State Polling guna memastikan sinkronisasi sirkuit yang andal.

Cloud Event Broker

Integrasi Firebase Realtime Database melalui protokol WebSockets (Stream) untuk transmisi data asinkron dua arah dengan latensi di bawah satu detik.

Reaktif Client UI

Aplikasi mobile Flutter yang dikompilasi via Ahead-of-Time (AOT) dengan skema Split-per-ABI guna merender visual telemetri secara mulus pada 60 FPS.

Panduan Instalasi Android

1

Unduh Berkas APK

Klik tombol unduh di atas menggunakan perangkat Android Anda untuk mendapatkan berkas biner aplikasi.

2

Izin Sumber Tidak Dikenal

Jika peramban atau File Manager meminta izin untuk menginstal aplikasi dari luar Play Store, pilih "Izinkan" atau "Allow from this source".

3

Bypass Play Protect

Saat muncul peringatan keamanan merah dari Google Play Protect (Aplikasi Tidak Dikenal), jangan klik OK. Ketuk "Detail Selengkapnya / More Details" lalu pilih "Tetap Instal / Install Anyway".
